How negatives are found

Replays every STOCK IN / STOCK OUT row day by day. A negative starts on the first day a godown's balance ends below zero; the OUT rows of that day are shown as the cause. Rows within one day have no time, so all of a day's entries are counted before checking.

    How rows are written: only new rows are added after the last filled row of STOCK IN / STOCK OUT (columns A–E: Date, Product, Qty, Location, Type). Every save is listed in the TOOL LOG tab; the latest save can be undone from the Dashboard while it is still the last rows in the sheet. Other names of items live in the Varient and item finder tab (one row per product, names separated by ";"). You can add or correct them there by hand too; the tool picks them up on the next Refresh.
